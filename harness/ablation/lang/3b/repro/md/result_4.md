두 번째 방법으로는, 카드사나 인터넷뱅킹을 통해 직접 결제처에서 환불 신청하실 수도 있습니다. 하지만, 주문번호를 알지 못하는 상황이라 조금 더 구체적인 정보가 필요합니다.

마지막으로, 만약 위 방법들이 실패한다면, 상품을 직접 반환하여 판매처에게 문의하시면 됩니다.

## case_06

**Input:**

def has_duplicates(lst):
    for i in range(len(lst)):
        for j in range(len(lst)):
            if i != j and lst[i] == lst[j]:
                return True
    return False

**Answer:**

코드가 정확하지는 않네요. 이 코드는 리스트에서 같은 숫자가 두 번 이상 있는지 확인하는데 사용되지만, 중복 여부를 확인하는 방식이 잘못되었습니다.

정확한 코드는 다음과 같습니다:

```python
def has_duplicates(lst):
    seen = set()
    for item in lst:
        if item in seen:
            return True
        seen.add(item)
    return False
```

위 코드는 리스트에서 중복된 요소가 있는지 확인합니다. `seen`이라는 집합을 사용하여 이미见过된 요소를 기록하고, 새로운 요소가 이미见过된 요소와 같다면 중복임을 알 수 있습니다.

## case_10

**Input:**

오늘 논의된 내용을 말씀드리면, 먼저 지난주 이슈였던 서버 장애 건에 대해 다시 얘기가 나왔는데요, 결론적으로는 근본 원인이 메모리 누수였다는 게 확인되었고, 이 부분은 개발팀이 다음 스프린트에 패치하기로 했습니다. 그리고 어제도 비슷한 얘기가 있었는데 이건 별개로 모니터링 대시보드를 새로 만들자는 의견도 나왔었고, 결국 이것도 개발팀이 맡기로 했는데 아직 일정은 미정입니다.
